This repository contains Python scripts written for personal and academic projects . Scripts are written to automate CARI-7 and related data analysis.

Contents: CARI-7automation automates the transfer of a .csv to a .DEG, edits default setting according to user input, opens and runs CARI-7, transfers files to a different folder, plots files, and puts all total doses from .SUM files into a table. SimulationFileScript uses a hardcoded flight path and user input latitude and longitude to generate simulated flight paths at various geographies, various altitudes, and for various durations. Simulation script allows for batch and single file creation based on user input. 

All scripts are designed to run with both CARI-7 and CARI-7A according to user specification. 

Requirements: Windows OS Python (version 13 or newer) install Python modules from list 
Modules list to install: - beautifulsoup4 - matplotlib - numpy - pandas - psutil - pyautogui - reportlab - requests
